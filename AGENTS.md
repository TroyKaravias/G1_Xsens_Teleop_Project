# Codex project guidance

Before changing this repository, read these files in order:

1. `g1_xsens_handoff/AI_HANDOFF.md`
2. `g1_xsens_handoff/START_HERE.md`
3. `g1_xsens_handoff/MILESTONE_2026-08-11.md`
4. The runbook relevant to the requested task.

Treat `AI_HANDOFF.md` as the durable context shared between Linux, Windows,
and cloud Codex sessions. Update it when a milestone, verified command,
deployment topology, safety boundary, or immediate next task changes.

Do not claim that hardware behavior is verified from unit tests alone. Keep
simulation, Jetson preflight, supported/harnessed robot tests, and unsupported
dynamic robot motion clearly distinguished. Never add credentials, private
keys, access tokens, or passwords to this repository.
